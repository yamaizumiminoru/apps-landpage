# v1.0.0 — four-app landing page

2026-09-24

Initial Japanese LP for Annotator-Connotator, Sprint Lab, Pronunciation Lab and Speaking Lab.

- Main message: **「通じる」の、その先へ。**
- Four owner-specified concepts developed into a coherent learner journey.
- Four color-coded product introductions with original, labelled explanatory UI previews.
- Functional Verb Frame demo and concern-based Lab guide.
- Responsive design, keyboard navigation, native FAQ, reduced motion, no-JavaScript fallback.
- Honest preview/publication status, language scope, AI limits and integration boundaries.
- Dependency-free static build, allowlisted preview server, 12 regression tests, optional multi-viewport browser checks.
- GitHub Actions validation, downloadable site artifact and guarded Pages deployment.

No application backend, user registration, payment processing or new cross-app integrations are added by this LP.
